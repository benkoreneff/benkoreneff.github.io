Workset Support

Workset is a local-first gym tracker for iPhone. Your training data is stored only on your device — see the privacy policy.

Getting in touch

Email workset.support@gmail.com. Workset is a one-person project, so a reply may take a few days.

Common questions

Where is my data?

On your iPhone, inside the app. There is no account and no server copy. Deleting the app deletes the data, so use Settings → Export Data first if you want to keep it.

How do I move my history to a new phone?

Use Settings → Export Data to write a CSV, move that file to the new phone, and use Settings → Import Data to read it back in. An encrypted iPhone backup restored to the new device also carries the data across.

Can I import from another app?

Workset imports Repcount CSV exports via Settings → Import Data.

The rest timer did not notify me.

The timer notification needs notification permission. Check iOS Settings → Workset → Notifications. The timer itself still runs and still shows on the Lock Screen whether or not notifications are allowed.

Does Workset sync between devices?

Not in this version. It has no server and no iCloud sync; export and import are the way to move data.
